Odoo AI Assistant

An AI chat assistant for Odoo 19 Community. Ask in plain language, in any language, and get answers inside Odoo. It can show your records, draw charts, read files and prepare changes, and nothing changes until you click Confirm.

Works with OpenAI, Anthropic Claude, Google Gemini and OpenRouter.

What you can do

  • Ask about Odoo: what an app can do, what a screen contains, and which app and screen you have open, all based on the real menus of your database.
  • Find and count records: "Find quotations for Acme", "How many leads are in each stage?" Results appear as tables.
  • Charts: bar, line, pie, doughnut, scatter or table. Open in Odoo opens the same chart in Odoo's graph and pivot views.
  • Files: attach a file from the + menu and ask about it, or ask about files already attached to records. PDF, Word, Excel and PowerPoint text (PDF table rows stay together), images with a preview, and text files.
  • Confirmed changes: create, update or delete records, post notes, schedule activities, attach files and run allowed business actions. Each one is previewed and runs only after Confirm.
  • Voice input from the + menu or Alt + V.
  • Anywhere: a magic-wand chat on every screen, the full AI Assistant app, and an AI conversations section in Discuss.

Private by default

  • Everything runs with each user's own Odoo permissions, only on the data an administrator chooses.
  • Record values, file contents and chart data stay inside Odoo. They're sent to the AI provider only if an administrator allows sharing and the user approves each result.
  • Typed messages go to the AI provider, so users shouldn't type confidential information.
  • Passwords, keys and security settings are always protected. Conversations are private to their owner.
  • The API key is readable only by administrators and isn't encrypted, so protect database backups.

Getting started

  1. Install the free MCP Server module and this app, together with the Python packages in requirements.txt.
  2. Open AI Assistant > Configuration > Settings: enable the assistant, choose a provider, paste its API key and choose a model.
  3. Choose which Odoo data the AI may read or change.
  4. Give users access on their Access Rights tab (AI > AI Assistant = Yes), then reload Odoo to see the magic wand.
